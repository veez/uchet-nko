# Сайт «Учет услуг НКО»: как опубликовать и обновлять

Сайт размещен на GitHub Pages: репозиторий `veez/uchet-nko`, адрес https://nkoplan.ru/

## Что где лежит

| Путь | Что это |
|---|---|
| `site/index.html` | Исходник страницы. Все правки делаются здесь. |
| `site/img/` | Скриншоты форм для сайта. |
| `site/fonts/` | Шрифты (лежат на сайте, без Google Fonts). |
| `site/favicon.svg` | Иконка во вкладке браузера. |
| `build.sh` | Сборка: из `site/` делает готовую папку `docs/`. |
| `docs/` | **Опубликованный сайт.** GitHub Pages берет его отсюда. Создается заново при каждой сборке, вручную не править. |
| `screenshots/src/` | Макеты форм 1С, из которых сняты скриншоты. |

## Как обновлять

1. Напишите Claude, что поменять.
2. Claude правит `site/index.html`, запускает `bash build.sh`, делает коммит и `git push`.
3. Через 1–2 минуты изменения видны на сайте.

Вручную то же самое:

```bash
bash build.sh
git add -A
git commit -m "Что изменилось"
git push
```

## Домен nkoplan.ru

Записи DNS (управляются у регистратора, серверы `ns1–ns3.registrant.ru`):

| Имя | Тип | Значение |
|---|---|---|
| `nkoplan.ru` | A | `185.199.108.153` |
| `nkoplan.ru` | A | `185.199.109.153` |
| `nkoplan.ru` | A | `185.199.110.153` |
| `nkoplan.ru` | A | `185.199.111.153` |
| `www.nkoplan.ru` | CNAME | `veez.github.io` |

Файл `docs/CNAME` с именем домена создает `build.sh`. Настройка в репозитории: Settings → Pages → Custom domain, там же Enforce HTTPS.

## Другой хостинг

Папку `docs/` можно загрузить на любой хостинг (Beget, Timeweb, REG.RU): ее содержимое копируется в папку сайта (обычно `public_html`).

## Когда формы начнут отправлять заявки

Сейчас формы только собирают текст для копирования, на сервер ничего не уходит. Если заявки будут приходить на почту автоматически, на сайт нужно добавить политику обработки персональных данных и галочку согласия (152-ФЗ).
